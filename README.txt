# FluentStep Pro
An installable, offline-capable mobile PWA for English learning, coding, Bible study and daily planning.

## Install on Android
1. Upload the contents of this folder to a static HTTPS host (GitHub Pages or Netlify).
2. Open the published HTTPS website in Chrome on your Android phone.
3. Tap the app's Install button, or Chrome ⋮ → Install app / Add to Home screen.
4. Open the installed FluentStep icon.

## Important reminder limitation
The app checks the schedule and plays sound/notifications while the page is running. Android can suspend browser/PWA background timers, so exact alarms are not guaranteed when the app is fully closed or the phone restricts background activity. For dependable closed-app alarms, a native Android app or server-backed push notification service is needed. Notifications require permission and HTTPS.

## Schedule included
05:00–05:30 Bible study; 05:30–06:30 English conversation; 07:00–08:00 podcast; 11:00–13:00 vocabulary and writing; 19:00–20:30 coding; 20:30–23:59 university subjects.
All data is saved locally in the browser. Use Export my data for a backup.
